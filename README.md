# GlassQuill

**Explainable detection of AI-generated text.** Paste an English text and GlassQuill tells you whether it reads as human-written or AI-generated, and shows the evidence behind the verdict.

Case-study project for Applications and Use Cases of Machine Learning (TE7483), AIML Department, Symbiosis Institute of Technology, Pune.

## Results

On 4,829 test texts the model never saw (HC3 + HAP-E + M4GT, split by question or document):

| Model | Accuracy | F1 | ROC-AUC | Humans wrongly flagged (FPR) |
|---|---|---|---|---|
| Perplexity threshold | 0.839 | 0.827 | 0.902 | 9.3% |
| TF-IDF + logistic regression | 0.959 | 0.959 | 0.990 | 3.0% |
| XGBoost (18 features) | 0.923 | 0.923 | 0.978 | 6.6% |
| DistilBERT (black box) | 0.961 | 0.963 | 0.997 | 7.1% |
| **GlassQuill verdict** (mean of XGBoost and LR) | **0.974** | **0.974** | 0.995 | **2.0%** |

- **MAGE**, 27 generators never seen in training: the verdict reaches 66.4% accuracy at 6.8% FPR and still catches GPT-4 91% of the time. Small open models (OPT, BLOOM, GPT-J) go undetected.
- **Paraphrasing** every sentence with T5: the verdict still catches 93% of AI texts (98% before).

## Run it

```bash
python -m venv .venv
.venv/Scripts/activate                 # macOS/Linux: source .venv/bin/activate
pip install torch --index-url https://download.pytorch.org/whl/cu128   # or plain `pip install torch` for CPU
pip install -r requirements.txt
cd web && npm install && npm run build && cd ..
python server.py                       # open http://127.0.0.1:8000
```

The trained models are in `models/`, so the website works without retraining.

## How it works

```
HC3 + HAP-E + M4GT ─► clean ─► balance per domain ─► split by group (70/15/15)
                                                            │
             ┌──────────────────────────────────────────────┴──────────────┐
      18 features per text                                             raw text
 (6 GPT-2 surprise + 12 writing style)                                     │
             │                                                ┌─────────────┴────────────┐
   Perplexity threshold, XGBoost                          TF-IDF + LR                DistilBERT
             └───────── verdict = mean(XGBoost, TF-IDF + LR) ─┘
                                   │
              explained with SHAP (features) and word weights (words)
```

- **Data:**
  - HC3 has ChatGPT (2022) and human answers to the same questions. HAP-E and M4GT add GPT-4o, GPT-4, Llama-3, Mixtral, Gemma and others across 17 domains.
  - That makes 32,000 texts, with equal human and AI counts in every domain.
  - MAGE is held out as the out-of-domain test.
- **Cleaning:** removes shortcuts that would let a model cheat. For example, HC3's human answers contained `do n't` (34% of them) and `URL_0` placeholders, which the AI answers did not.
- **Features:** GPT-2 measures how predictable each word is (perplexity); AI text is more predictable. The style features cover sentence rhythm (burstiness), vocabulary richness, punctuation and readability.
- **Training:** hyper-parameters are tuned with 5-fold GroupKFold on the training set only, and the test set is used once, at the end.
- **Explanations:** SHAP for the XGBoost features, exact word weights for the TF-IDF model, and LIME for DistilBERT.

## Reproduce the study

```bash
python run_pipeline.py --quick      # every stage on a small sample, about 10 minutes
python run_pipeline.py              # the full study, about 1.5 hours on a laptop GPU
python run_pipeline.py --stages evaluate ood paraphrase explain   # results only, reuses saved work
python -m pytest tests -q           # 25 API tests
```

Datasets download automatically on first run. Every stage saves its output, so any stage can be rerun on its own. The seed is fixed at 42, so a rerun gives the same numbers.

## Security and privacy

Pasted text is never stored or logged. The API (`server.py`):
- accepts 50 words to 12,000 characters and strips invisible characters that could sway the verdict
- refuses text that isn't English prose
- caps the request size and rate-limits each IP
- sends strict security headers

Each of these has a test in `tests/test_server.py`.

For deployment, set `SITE_URL` when building the website (`SITE_URL=https://your-domain npm run build`). If the server sits behind a reverse proxy, also set `GLASSQUILL_TRUST_PROXY=1`, so the rate limit sees each visitor's real IP.

## Limits

- A detector score is a second opinion, **never proof** on its own.
- Plain, predictable writing (common for non-native writers) can look AI-like.
- Paraphrasing tools, heavy editing and small open models can fool it.
- English only, and best on 50 to 400 words.
